# Security policy

Do not report a suspected vulnerability in a public issue. Send a private report through
the Security tab of the `VIC-E-com/tokensaver-plugin-sdk` GitHub repository.

Include the affected version, platform, reproduction details, impact, and any proposed
mitigation. Do not include credentials, private plugin content, or unrelated personal data.
The maintainers will acknowledge a complete report, investigate it, and coordinate a fix
and disclosure appropriate to its severity.
